## macOS 正式版

- 按 **Ctrl+V** 打开剪贴板历史。日常复制和粘贴仍用 **⌘C / ⌘V**。
- 个人适配版使用 **⌘V** 打开历史、**Ctrl+C / Ctrl+V** 复制和粘贴。这组自定义映射仅用于个人版本。
- 在原窗口打开历史并点击条目后，应用会切回原窗口并粘贴。首次使用自动粘贴，请在「系统设置 → 隐私与安全性 → 辅助功能」允许 Smart Clipboard。
- 下载 macOS arm64 压缩包，解压并将应用拖入「应用程序」。适用于 Apple 芯片和 macOS 13 或更新版本。应用在菜单栏后台运行。

## Windows

下载 Windows x64 压缩包，解压后运行 SmartClipboard.exe。按 **Win+V** 打开历史，**Ctrl+V** 正常粘贴。
